# B 族统一协议 v1.0：世界模型组执行注记（2026-10-27）

统一协议正文为"WM-Verdict Unified B-Family Image Degradation Protocol v1.0"，按其执行。以下记录我方的执行口径、协议偏离备注和实现位置。

## 首批设置（裁决 2026-10-27）
- 类型与档位：高斯模糊、雾、缩放模糊，各取第 2/5/9 档（noise 12/15/19、32/35/39、22/25/29）。
- 毛玻璃弃用：参数表存在剂量缺陷，待两组商定修正版。代码与 SHA 不变，属于档位选择变更。
- 代码：LIBERO-plus commit 4976dc3，`env_wrapper.py` sha256 e91d7b7b…f39c3c。函数原样取用；调用方式同上游调用点：PIL 图像 → 函数 → `.astype(np.uint8)`。
- 运行时：劣化在单独子进程中运行（`libero/bfam/bcorrupt_server.py`），依赖固定为 numpy 1.22.4、scikit-image 0.21.0、scipy 1.10.1，两台机器版本一致。原因：雾函数在 NumPy 2 下不可运行。

## 第 6 节执行注记（裁决 2）
- B 模拟的是脏相机，所以只劣化真实相机拍出的帧。想象帧是模型的内部状态，不是相机输出，一律不劣化。
- 开环：只劣化 t = 0 的真实首帧。OpenWAM 一次想象中后 12 次接力调用读的是它自己的想象帧，不劣化。
- 闭环：策略每次读到的真实画面都劣化，与策略组同口径。环境步序号 = 已执行步数，t = 0 为复位后的观察。
- 固定动作回放（开环真值）与闭环分开报告。真值回放只执行动作，图像不起作用。

## 渲染路径与对照（裁决 1）
- LingBot-VA 原生在 128 渲染，主锚库基线即无扰动档，经 sham 检查确认。
- OpenWAM-α 原生在 256 渲染。B 族按协议在 128 渲染、先劣化，再经 OpenWAM 自己的预处理（旋转 180° + LANCZOS 放大进画布）。为此补跑 100 个单元的"128 渲染、无劣化"作为 B 族专用对照（B0）；表注写明它与主基线不同源（渲染路径不同）。

## 判据抗劣化门槛（裁决 3）
- 真实帧按每个类型、每个档位加劣化，用已部署的判据测 TPR/TNR。85% 线按"任务 × 类型 × 档位"逐格适用。
- 不过线的格照常采数据，判定列标"判据在此档不可靠，pending"。
- 帧来源：各模型主锚库基线单元的真值重放，每 4 步取一帧，标签为模拟器的成功判定（`libero/bfam/bgate.py`）。

## 随机数与记录（第 5、7 节）
- 种子 = sha256("<unit_id>|<环境步>|agentview|<函数>|<档位>") 的前 8 位十六进制转整数；算法为 numpy 1.22.4 的 MT19937（np.random.seed）。劣化在独立进程中运行，不影响仿真和策略的随机数流。
- 记录字段：model_id、checkpoint、task_id、episode_id、initial_state_id、seed、libero_plus_commit、source_sha256、corruption_type、severity、noise_code、camera、render_resolution、start_step、end、rng 规则、policy_preprocessing、success、completion_step。
- 每个单元另存：t = 0 劣化前后的画面对；闭环每 50 步一帧劣化画面；真值状态与动作；想象画面。

## 协议偏离备注（裁决 3）
1. uint8 截断偏置：上游 `.astype(np.uint8)` 截断而不是四舍五入，像素平均低 0.5 个灰度级。
2. 边缘劣化偏弱：边缘与中间的变化幅度之比，高斯约 0.65，缩放约 0.85。
3. 高档持平：雾 5→9 每帧只差 0.7–1.0 dB，9→10 平均回升；缩放模糊 7→8 持平。都不在第 2/5/9 档之间。
