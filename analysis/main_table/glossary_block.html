扰动族与档位

缩写全称具体做法各档数值
none无扰动基线主锚库起点，不加任何扰动—
A物体初始位置偏移（Anchor / displacement）把目标物体的初始摆放区域改成边界外的一个点再采样；A 族用自己的一套原生采样起点，表内与 A0 比较。偏移方向：T0 书 +y，T1 碗 +x，T2 摩卡壶 +x，T3 白杯 +x，T4 白杯 −yA0 = 原生区域（零偏移，A 族自身基线）；A1 = 正好在原生区域边界；A2 / A3 / A4 = 超出边界 2 / 5 / 10 cm（T1 的 A4 降为 7 cm：10 cm 已到机械臂可达极限）
P机器人初始位姿（Pose）机器人初始关节角加均匀噪声；P 族用自己的起点，表内与 P0 比较。原生分布约 ±0.06 rad每个关节噪声幅度 P0 / P1 / P2 / P3 / P4 = 0 / 0.02 / 0.06 / 0.12 / 0.24 rad（P0 = P 族自身基线；P1、P2 在原生范围内，P3、P4 超出）
O遮挡（Occlusion）在模型读入的第一帧主视角画面中央贴一个黑色正方形（腕部相机不动）；只改模型输入，不改物理正方形边长占画面边长 O1 / O2 / O3 / O4 / O5 = 1/16、1/8、3/16、1/4、5/16
Em目标物体质量（Mass）目标物体及其子部件的质量、惯量同乘系数Em1 / Em2 / Em3 / Em4 = ×1.5 / ×2 / ×4 / ×8
Ef接触摩擦（Friction）目标物体、夹爪指垫、桌面三者的摩擦系数同乘系数（MuJoCo 取接触双方较大值，所以三者一起缩放）Ef1 / Ef2 / Ef3 / Ef4 = ×0.8 / ×0.6 / ×0.4 / ×0.2
G机械臂控制器增益（Gain）操作空间控制器刚度 kp 乘系数 f、阻尼 kd 乘 √f（阻尼比不变）；机械臂跟随指令变软、变慢G1 / G2 / G3 / G4 = f 取 0.9 / 0.75 / 0.55 / 0.4
K外力推动（Kick / push）在第 t 个环境步之后，把目标物体沿 A 族的方向推开 d；只在闭环中做K1–K3：t = 60，d = 2 / 5 / 10 cm；K4–K6：t = 160，d = 2 / 5 / 10 cm；K7–K9：t = 260，d = 2 / 5 / 10 cm
N1单次丢动作第 50 个环境步执行零动作（保持不动），之后恢复只有一档
NR随机丢动作（Random drop）每一步独立以概率 p 被替换为零动作；同一单元两遍用同一掩码NR1–NR5：p = 5% / 10% / 20% / 30% / 40%
NL短延迟（Latency）每一步执行的是 d 步之前发出的指令；历史不够时执行零动作NL1–NL5：d = 1 / 2 / 3 / 4 / 5 步（0.05–0.25 秒）
NLw长延迟（Latency, wide）同 NL，延迟更长，跨过两个模型的重规划间隔（LingBot-VA 每 16 步、OpenWAM-α 每 32 步重规划一次）NLw1–NLw5：d = 4 / 8 / 16 / 32 / 64 步（0.2–3.2 秒）
B0图像腐蚀族的对照走 B 族的 128 px 渲染路径，但不加腐蚀；B 族的基线—
Bg高斯模糊（gaussian blur）闭环中模型读入的每一帧主视角画面都被腐蚀（腕部不动），用 LIBERO-plus 的原版腐蚀函数，只改模型输入数字是 LIBERO-plus 的强度参数：2 / 5 / 9，越大越重（例：Bf5 = 雾，强度 5）
Bf雾（fog）
Bz缩放模糊（zoom blur）

环境步频 20 Hz：1 步 = 0.05 秒。上面的档位定义对四个模型相同；Cosmos Policy 与 UVA 的原始档位值已按同一张表换算成这里的缩写。
