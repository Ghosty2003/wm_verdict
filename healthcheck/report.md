# B 族劣化函数体检：发现两项缺陷，B 暂停（2026-10-27）

**对象**：LIBERO-plus commit `4976dc30028e805ff8094b55501d532c48fec182`，`libero/libero/envs/env_wrapper.py`，sha256 `e91d7b7b…f39c3c`（已核验）。函数为高斯模糊、雾（含 `plasma_fractal`）、毛玻璃，原样取用，未做任何改动。调用方式与上游调用点一致：PIL 图像 → 函数 → `.astype(np.uint8)`。
**图像**：6 张真实 LIBERO agentview 帧，128×128，t5、t3 各取开头、中段、结尾。雾和毛玻璃每档取 5 个种子求平均。
**环境**：按 LIBERO-plus 固定的依赖（numpy 1.22.4，scikit-image 0.21.0，scipy 1.10.1）。另用 numpy 2.2.6 做对照。

## 缺陷 1：毛玻璃的剂量不单调，2/5/9 三档几乎没有剂量差

- **证据**：
  - 1→2、3→4、5→6、8→9 这四步，6 张帧上 PSNR 全部不降反升；换 SSIM 也是同样四步、同样结果。因此不是 PSNR 这个指标造成的假象（`dose_curves.png`）。
  - 1–10 全档的平均 PSNR 只在 20.4–21.9 dB 之间变动，跨度 1.5 dB；高斯模糊同一跨度是 9.9 dB。
  - 选定的 2/5/9 三档在每张帧上都按顺序下降，但 5→9 每帧只差 0.07–0.40 dB，第 5 档和第 9 档实际上是同一剂量。
  - 联系表（`sheet_glass_blur.png`）上看，模糊程度随档位增加，但像素错位成分在第 9、10 档反而变弱。
- **原因**（读代码）：
  - 参数表里 σ 逐档增大，迭代次数却从 3 降到 2 再降到 1：(0.5,1,**3**) … (1.1,3,**2**) … (2.2,5,**1**)。
  - 函数在错位之后还会再做一次高斯模糊，σ 越大，越能把错位噪声抹平。所以"σ 更大、迭代更少"的档位反而更接近原图。
- **附带观察**（与 ImageNet-C 原始实现相同，不在本次缺陷范围内）：
  - 交换语句 `x[h, w], x[h', w'] = x[h', w'], x[h, w]` 作用在 numpy 视图上，实际效果是复制，不是交换。在 128×128 上走一遍（d=1），16384 个像素里只剩 11301 个不重复。
  - `randint(-d, d)` 的取值范围是 [-d, d-1]，不对称。实测全局平移小于 0.07 像素，可忽略。
- **建议修法**（需两组商定）：
  - **(a) 推荐**：首批用缩放模糊替换毛玻璃。缩放模糊在同一文件里，代码和 SHA 都不用改；替换前按同样五项再体检一次。
  - **(b)** 只改毛玻璃的参数表，让迭代次数不随档位递减。这会产生新的 SHA，两组都要重跑。
  - 不建议在现有毛玻璃上另选档位：全程只有 1.5 dB 的跨度，找不出三档间距合理、又单调的组合。

## 缺陷 2：雾函数在 NumPy ≥ 2 下无法运行

- **证据**：`plasma_fractal` 里用了 `np.float_`，NumPy 2.0 已删除这个名字。在 numpy 2.2.6 下调用直接报 `AttributeError`（`report_current.json`）。我方两个模型的运行环境都是 numpy 2.2.6；LIBERO-plus 的 `requirements.txt` 固定的是 `numpy==1.22.4`。
- **建议修法**：
  - **(a) 推荐**：劣化步骤放在一个独立进程里，用 LIBERO-plus 固定的依赖运行（numpy 1.22.4，scikit-image 0.21.0）。代码和 SHA 都不变，协议里写明这个运行时要求。
  - **(b)** 把 `np.float_` 改成 `np.float64`。行为不变，但会产生新的 SHA，两组都要重跑。
- **请策略组说明**：你们运行时用的是哪个 numpy 版本。如果是 2.x，说明你们手里的雾函数已经被改过，和协议里的 SHA 对不上。

## 裁决（2026-10-27）与缩放模糊补充体检

- **裁决 1**：首批三种改为高斯模糊、雾、缩放模糊。毛玻璃在现行参数表下剂量不单调（模糊会抹平打乱的痕迹，第 5 档与第 9 档无法区分），不能当剂量轴用，弃用，待两组商定修正版。这次改的是档位选择，不是代码，SHA 不换。
- **裁决 2**：雾在单独的子进程里运行，依赖固定为 LIBERO-plus 的 numpy 1.22.4 / scikit-image 0.21.0，代码和 SHA 都不变。
- **裁决 3**：uint8 截断偏置、边缘劣化偏弱、雾高档饱和三条记入协议偏离备注；随机数隔离层按协议第 5 节实现。
