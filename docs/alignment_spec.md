# 跨组扰动对齐规范（草案 v0.1，2026-10-23）

- **适用范围**：世界模型组（WM-Verdict，本项目）与策略组在 LIBERO 上的扰动实验。
- **目的**：让两组的设置可以逐行对应；凡是数字要并进同一张表的，口径必须先在本文对齐。
- **状态**：草案，世界模型组内部审阅后再发给策略组。标 〔待策略组填〕 的格子需要对方补充；标 〔待定〕 的需要两组共同决定。
- **基本规则**：一切"无法统一"的点都必须显式写在本文里（主要在第 3 节矩阵的"换注入点后适用"和"不适用"两列），不做口头约定。

---

## 1. 统一分类

### 1.1 主分类：2 × 2，注入时刻 t 作为参数

| | **一次性**（只在第 t 步施加一次） | **持续**（从第 t 步起每一步都施加） |
|---|---|---|
| **改信息**（改变某一方看到的观测，不改变物理世界） | 单帧遮挡（黑方块）、单帧模糊 | 图像扰动五种（运动 / 高斯 / 缩放模糊、雾、玻璃模糊）、传感器噪声 |
| **改物理**（改变世界状态或动力学） | 物体初始位置、机器人初始位姿（t = 0）；回合中途推动物体（t > 0） | 动作丢弃、动作延迟、动作增益、动作旋转、执行器增益、控制频率错配 |

- **t 是每个设置的必填参数**。t = 0 表示在初始状态上施加（回合开始前或复位时）。
- **"改物理"包括作用在动作通道上的干预**（丢弃、延迟、增益）：它们不改变任何一方看到的画面，而是改变实际执行的动作，从而改变物理轨迹。需要细分时，用第 1.3 节的"通道"列区分"状态"和"动作"。
- **与策略组原表的差异**：**黑方块遮挡**在策略组原表中的归类为〔待策略组填：原归类〕，本规范将其归入 **"改信息 × 一次性"**（遮挡只改变观测、不改变物理，且施加在单个时刻 t）。请策略组按此更新原表。

### 1.2 世界模型组特有的两层标注

策略组可以忽略这两层，但结果表中保留这两列（填"—"即可），以便并表。

| 标注 | 取值 | 含义 |
|---|---|---|
| **注入分支** | 模型输入 / 共享起点 / 真值分支 | **模型输入**：扰动进入模型读取的观测（fidelity 轨道）。**共享起点**：扰动改变模型与真值共同的出发状态，模型的首帧就是扰动后的真实画面（verdict 轨道）。**真值分支**：只在模拟器执行时施加，模型不知情（verdict 轨道，不可见的物理变化） |
| **训练覆盖** | known / 微调外 / 预训练未排除 | 该扰动档位是否落在被测模型的训练分布内，必须附证据出处。"微调外"均隐含"预训练覆盖未排除"，除非有定向核实 |

### 1.3 每个设置的坐标（一行一个设置）

`轴 1（信息 / 物理） × 轴 2（一次性 / 持续） × t × 通道（图像 / 状态 / 动作） × 注入分支 × 训练覆盖`

**每个设置都必须配 sham**，并做"参数生效断言"：
- **状态与动作通道**：同一起点、同一动作序列，扰动开和关时的逐步状态必须不同；sham 必须为零差异。

### 2.3 环境物体初始位置：与环境无关的档位定义

- **参考系**：该任务目标物体在原生采样器中的**初始摆放区域**，即 BDDL `:regions` 中该物体所在区域的 `:ranges` 矩形。档位按"越过区域边界的距离"定义，不按绝对坐标定义。这样不同任务、不同环境都可以照搬。
- **方向**：每个任务固定一个方向，选择原则是远离其他物体、移动后物体仍可放置（无碰撞、不掉落）。方向和理由要写进协议。我们的取值：t5 的书沿 +y（远离收纳盒和杯子），t3 的碗沿 +x（远离机器人）。
- **实现**：把区域矩形整体平移到"越界 d"的位置，由原生采样器在新区域内采样；不手写物理状态。

| 档位 | 定义 | 覆盖标签（以 LingBot-VA 为例；各模型须自行举证） |
|---|---|---|
| A0 | sham：区域按原值改写，与未改写路径同种子逐位一致 | known |
| A1 | 区域平移到边界上（d = 0） | known（边界） |
| A2 | 越界 d = 2 cm | 微调外 |
| A3 | 越界 d = 5 cm | 微调外 |
| A4 | 越界 d = 10 cm | 微调外 |

- **可达性降档规则**：如果 A4 会让任务在物理上必然不可完成（超出机械臂可达范围），允许降档，但必须做探针（确认无碰撞、与基座距离有可抓余量），探针图存档，并在表注写明降档原因和实际 d。我们的 t3 A4 因此降为 7 cm。
- **前置验证**：每个档位的初始状态要单独冻结，并过逐位重放验证（同一种子两次新建环境，逐步状态完全一致）。
- **RNG 注意事项**：robosuite 每次复位都会消耗全局随机数抽取机器人初始噪声。任何改变这一抽取次序的修改（例如换噪声类型）都会让物体摆位与原生路径不同，即使幅度为 0。因此族基线必须走与其余档位相同的代码路径。

### 2.4 图像扰动：实现与档位

- **实现**：一律使用 LIBERO-plus 原版扰动函数和参数文件，不改写。代码文件与参数文件的 SHA-256 入档（第 5 节）。图像尺寸、颜色空间、施加位置（缩放前还是缩放后）必须写明。
- **档位编号**：沿用 LIBERO-plus 原版的 1–10 档编号。
- **世界模型组首批**：每种取 3 档，与策略组的编号对齐。建议取第 〔待定，建议 2 / 5 / 9〕 档，分别对应轻、中、重。最终取哪 3 档由两组确认后写进协议。
- **策略组**：全 10 档。

### 2.5 动作丢弃与延迟：可复现性要求

- 掩码序列（每步是否丢弃）或延迟序列，必须由一个**落盘的种子**生成，并把**完整序列本身**随结果落盘。
- 同一个 unit 的两次真值执行必须使用同一序列。
- 丢弃时执行什么、延迟起始阶段的缓冲动作取什么，都必须写进协议。

## 3. 模型类别与适用性矩阵（本规范的核心）

### 3.1 两类模型

- **策略模型（闭环）**：每一步读取真实观测、输出动作，与模拟器交互。策略组的被测对象属于此类。
- **想象模型（开环）**：只读取锚点的首帧（以及指令、本体状态），之后完全在自己的想象中滚动到 H，并给出"会不会成功"的判断；真值分支在模拟器中开环重放同一串想象动作。世界模型组的被测对象属于此类。
  - 想象模型另有一个**闭环对照列**（真实画面回填）。它不进配对 verdict 表，只作参照。

关键差异在于：**想象模型在 t > 0 时不读取任何真实观测**。所以凡是在 t > 0 改变观测的扰动，都无法进入它的想象。

### 3.2 适用性矩阵

取值：**适用** / **换注入点后适用**（写明换成什么） / **不适用**（写明原因）。

| 设置 | 策略模型（闭环） | 想象模型（开环） |
|---|---|---|
| 环境物体初始位置（t = 0） | 适用 | **适用**。注入分支 = 共享起点：模型首帧就是扰动后的真实画面 |
| 机器人初始位姿（t = 0） | 适用 | **适用**。注入分支 = 共享起点 |
| 回合中途推动物体（t > 0） | 适用 | **换注入点后适用**：只在真值分支第 t 步施加，模型不知情（注入分支 = 真值分支，属于不可见的物理变化）。与策略模型的同名设置**不可并表**：策略模型看得到推动后的画面，想象模型看不到 |
| 图像扰动五种，t = 0 起持续 | 适用 | **换注入点后适用：改为"首帧扰动"**。想象模型只读首帧，持续扰动退化为只扰动首帧（注入分支 = 模型输入，fidelity 轨道）。真值分支开环执行想象动作，不受图像扰动影响。另可进闭环对照列（每步回填扰动后的画面） |
| 图像扰动，t > 0 起持续（如"第 50 步起模糊"） | 适用 | **不适用**（开环想象）：第 t 步之后想象模型不读真实画面，扰动无处注入。**只进闭环对照列** |
| 黑方块遮挡，t = 0 | 适用 | **换注入点后适用：首帧遮挡**（注入分支 = 模型输入） |
| 黑方块遮挡，t > 0 | 适用 | **不适用**（开环想象），原因同上；**只进闭环对照列** |
| 动作丢弃 | 适用（施加在策略输出与环境之间） | **换注入点后适用**：在真值分支执行想象动作时按同一掩码丢弃，模型不知情（注入分支 = 真值分支）。不能注入想象内部：想象模型的动作与画面是联合生成的，外部丢弃会破坏配对 |
| 动作延迟 | 适用 | **换注入点后适用**：同动作丢弃，在真值分支执行时延迟 |
| 动作增益、动作旋转、执行器增益、控制频率错配（世界模型组在 DINO-WM / MMBench2 上已用） | 适用 | 适用（注入分支 = 真值分支） |

**并表规则**：
- 同一设置在两类模型上的注入分支不同时（例如图像扰动对策略模型是每步注入，对想象模型只能注入首帧），两类模型的数字分开列表，不放进同一列比较。
- 只能进闭环对照列的格子，不参与想象模型的配对 verdict 统计。

## 附：建议追加段——存档最低要求（世界模型组 2026-11-13 起执行，建议两组对齐）

为了让每个进表的数字都能事后复核，世界模型组从 2026-11-13 起，对每个评测单元强制落盘下面这份最低清单（缺任何一项，作业会报错停跑，也不会写结果行）。建议策略组和队友侧（Cosmos Policy、UVA、VPP2）按同一清单存档；并表时以此作为"数据完整"的判定口径。

- **结果行**：单元编号、扰动设置及完整参数、种子、机器名和 GPU 型号、成败、首次成功步（失败也要有这个字段，值为空）、单元数据文件路径。
- **闭环**（每一遍都要）：
  - 指令动作和实际执行动作，全步；
  - 逐步成败序列；
  - 每次规划调用的模型想象输出（latent 或帧，至少一种）；没有想象输出的纯策略模型此项填"—"；
  - 模型每次读入的真实观测。
- **开环**：想象全序列、判定器实际输入的帧、想象动作、真值回放的执行动作。
- **自检**：动作长度、逐步成败长度与记录的步数一致；逐步成败序列和记录的成败、首次成功步一致。
