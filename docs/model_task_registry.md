## 2. 结构性排除（未进入实测）

| 模型 | 类别 | 理由 |
|---|---|---|
| FastWAM（`ZibinDong/fastwam_libero_uncond_2cam224`） | E1 | 想象与动作各自独立生成，联合一致性双向断开 |
| LaWAM（`jialei02/lawam-libero-sft-lerobot`） | E2 | 单步世界模型，只输出特征、不能解码成画面，无 rollout 能力 |
| VLA-JEPA（`lerobot/VLA-JEPA-LIBERO`） | E3 | 世界模型只是训练期辅助损失，部署时不运行 |
| OpenWAM FDM（Stanford） | 不可得 | 没有公开的 LIBERO 检查点 |
| dWorldEval | 不可得 | 没有代码和权重 |

## 3. 注

- **"已完成"的含义**：数据跑完且 verify 通过，或 FAIL 项有书面放行。DINO-WM、MMBench2 的检查 6 FAIL 都发生在 2026-10-13 规则修订之前；修订后非单调只记 WARN，已出的报告保留原判（`verify_run.py` 头注释）。
- **扰动通道的差异**：DINO-WM 和 MMBench2 的扰动都在动作或动力学通道，模型看不到；LIBERO 两族扰动都在初始状态，扰动后的场景就在模型的条件首帧里，模型"看得到"。
