## 实现定义补充（2026-10-26 裁决）

- **E 摩擦（Ef）**：MuJoCo 接触摩擦取两个几何体中的较大值。为使"对夹爪、对支撑面"两组接触对按同一倍率缩放，**目标物体、夹爪垫（`gripper0_finger*_pad_collision`）、支撑面**三组几何体的摩擦同乘倍率。支撑面指 reset 后与物体接触的几何体：t5 为桌面几何体 g14，t3 为 `table_collision`。
  - 只乘滑动摩擦（`geom_friction[:, 0]`），扭转、滚动摩擦不动。
  - 副作用照记：夹爪垫、桌面对其他物体的摩擦同变。
  - 每个 unit 用接触读数核验实际摩擦等于倍率乘原合成值（冒烟误差 0）。
- **E 质量（Em）**：目标物体子树各 body 的质量与转动惯量同乘倍率，`body_subtreemass` 按同一差值更新，不调 `mj_setConst`（保证 ×1 档逐位不变）。
- **G**：OSC 控制器 kp × f，kd × √f（阻尼比不变）。
- **N 族"零动作"**：7 维全零，即 OSC 增量位姿为 0（保持位姿），夹爪符号为 0（PandaGripper 保持当前目标，不松爪）。含义：运输途中丢指令不会导致掉落，这是比"松爪"温和的故障模型。
- **开环复用**：E / G / N 不进模型输入，想象与 verdict 与主锚库基线逐 unit 相同，只重放真值（协议推论）；闭环重跑。
- **质量 ×8 不影响成功**：照实记录，平的剂量曲线也是曲线。
- **O 遮挡**：只遮 agentview 路，腕部相机不动。档位为图像边长的比例：1/16、1/8、3/16、1/4、5/16（在 128 像素下即 8 / 16 / 24 / 32 / 40 像素，与策略组数值对齐）。每个模型在自己的输入分辨率上换算，方块位于画面正中心。
- **K 推动时刻**：t ∈ {60, 160, 260}，两任务同用绝对步数，对应抓取前、操作中、主动作后三个阶段。阶段对应关系写表注，t 本身不随模型或任务调。仅闭环轨，幅度沿用 A 的厘米档。
- **F 单次全帧遮挡（2026-11-12，v2）**：名义 t ∈ {60, 160, 260}（与 K 同）。实现规则：t 之后（含 t）第一次规划调用读入的主视角帧整帧置 0（新数组，原观测不动），在任何模型预处理之前；腕部帧原对象原样传入；想象帧不碰。LingBot-VA 每一步观测都作为关键帧缓冲，规划调用时整段（16 帧）流式 VAE 编码进 KV cache——置黑的是规划调用那一步的观测（= 该段最后一帧），之后作为历史留在 KV cache 与因果 VAE 缓存里（与 O 族 t=0 遮挡帧同理），其余帧不动。OpenWAM-α 每次调用只读当前一帧、无视觉记忆，置黑只直接影响该次调用的 32 步动作。注意：回合在置黑点之前已成功的单元（LingBot 成功即停；OpenWAM 按 reach_anytime 判）置黑不会改变结论，记录字段 blackout_applied / blackout_after_success 标明。
- **B 首批**：高斯模糊、雾、玻璃模糊（整体钝化、全局对比度、局部畸变三种机制），档位 2 / 5 / 9。运动模糊和缩放模糊与高斯同族，留第二批。等策略组代码 SHA 到位才开跑。（**2026-10-27 更新**：玻璃模糊被缩放模糊替换，见变更记录。缩放模糊与高斯同属模糊，但机制是径向缩放叠加，不是各向同性钝化；运动模糊仍留第二批。代码 SHA 已定为 LIBERO-plus 4976dc3。）
