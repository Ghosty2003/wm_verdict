# Check 7 第一层初审口径（2026-10-20 裁决 3）

对象：lingbot_famA / lingbot_famP 中按**规则 v1（单帧、到达过即成功，k = 1）**判为 false-safe 的 333 个 unit：t5 187 条，t3 146 条。每个 unit 一张三联图，从左到右：

1. 想象终点帧（第 520 帧）
2. 想象中首次触发判据的帧（规则 v1，帧号写在标题里）
3. 真实终点帧（第 520 步；模拟器判定失败）

每联都是两路相机左右拼接：左半是 agentview，右半是腕部相机。

**判定对象是想象终点帧（第 1 联）"像不像成功"。** 第 2 联、第 3 联只作参照。三类标签：

| 标签 | t5：书放进收纳盒的后格 | t3：碗放进柜子底层抽屉并关上 |
|---|---|---|
| `looks_success` 像成功 | 书清楚地位于收纳盒后格内（agentview 可见书在后格中）；夹爪已松开，或至少书已明显落进格中 | 抽屉关着，画面中任何地方都看不到碗（与碗在抽屉里一致）；或抽屉开着、碗在抽屉内，且关抽屉的动作已完成 |
| `not_success_but_triggered` 不像成功但判据触发 | 书明显不在后格：仍在夹爪中且悬在盒外或格口上方、在桌上、在前格、掉落等 | 碗清楚地出现在抽屉外（桌上、台面、夹爪中），或抽屉明显开着且碗不在里面 |
| `borderline` 边界 | 画面退化或遮挡到无法判断；书在格口边缘、部分插入等 | 画面退化、遮挡；碗是否可见无法确定 |

规则：
- 只看第 1 联下结论。第 3 联是现实结果，不能用来推断想象画的是什么。
- 每条写一句理由，描述看到的内容。
- 拿不准一律标 `borderline`，不要猜。
- 记录凡涉及"判据触发"时注明规则版本：`trigger_rule: v1_k1`。

## 2026-10-21 补充一：t5"插进格子但没松手"按模拟器语义判定（裁决 2）

**标准**：画面所描绘的状态如果真实发生，模拟器判不判成功。

**依据**（`t5_release_check.json`，脚本 `libero/t5_release_check.py`）：
- 数据：famA/famP 全部 500 条 t5 真值重放（各 250 条），逐位重放，共 260,000 步；逐步成功标志与存档一致。
- 逐步记录 LIBERO 目标谓词的两个组成部分：`region.check_contain(book)` 和 `region.check_contact(book)`；以及 robosuite 的抓取判定 `_check_grasp`，即两指都接触书。
- **"书在后格内且夹爪仍抓着"共 16,558 帧，分布在 309 个 unit 中。模拟器在这 16,558 帧上全部判成功**（16,558/16,558），没有例外。
- 全部成功帧共 32,700 帧，其中一半出现在仍被抓着的阶段。
- 附带发现：对这个区域，`check_contact` 在每一帧都返回真，所以 `In` 在 t5 上实际上等价于几何包含。

**结论**：
- 想象终点"书已落进后格、夹爪仍夹着"标"像成功"，加子标签 `not_released`。
- 170 条 t5 像成功全部是这种情形（每条初审理由都写明仍被夹着）。**标签翻转 0 条。**
- 这一判定成立的前提是：画面上能分清"书已落入格内"与"书悬在格口上方"。后者在模拟器中不算成功，真实失败轨迹的终点多是这种情形。人工复核时请重点核对这一点。

## 2026-10-21 补充二：t3"像成功"的子标签（裁决 3）

"抽屉关着且画面中无碗"算"像成功"。在此基础上，按整条想象序列区分子标签（依据各 unit 每 20 帧一张的想象胶片 `filmstrips_t3/`）：
- `bowl_entered_visibly`：某一帧清楚地画出碗在开着的底层抽屉里，或正被放进去；随后抽屉关上。
- `bowl_vanished`：从未画出碗进抽屉，碗凭空从画面中消失。这是幻觉签名。
- `unclear`：无法判断。

初审结果：139 条 t3 像成功全部是 `bowl_entered_visibly`，`bowl_vanished` 为 0。待人工复核。
