## 1. 四项烟雾测试

### 1.1 联合一致性（同前缀换动作，后续画面须变）

- **做法（仅测试用补丁，不进正式路径）**：同一起始帧、同一本体状态、同一种子；把动作的噪声级固定为 0，初始动作分别替换为 (i) 模型自己生成的动作、(ii) xyz 取反后的动作，比较生成的 9 帧。
- **结果**：(i) 与 (ii) 在第 1–8 帧的 PSNR 为 24.9、21.6、20.5、19.9、19.8、19.7、19.8、19.8 dB，逐像素平均差 3.8–9.9；(i) 重跑两遍逐位一致。**画面依赖动作，联合一致性成立。**
- 附：固定动作版与自由联合生成版的画面接近（PSNR 33–49 dB），说明补丁没有把模型推到异常状态。

### 1.2 自有策略在想象帧上的输出健康度（WorldVLA 栽在这里）

- OpenWAM 没有 token 语法，不存在"格式畸形"。这里把非有限值、指令饱和（|值| > 1）、rot6d 非正交、夹爪越界计为畸形。
- **9 条完整想象 × 544 个动作，上述各项都是 0。**
- 动作幅度稳定：平均 |xyz| 0.15–0.31，没有趋零或饱和。
- **画面运动量**：前 5 块每帧平均变化约 4.6，第 9 块之后降到约 0.7，大约 250 步后画面趋于静止。在标定口径下，这与真实成功时刻吻合（第 161–225 步完成任务后手臂停住），属于合理行为；在另两个口径下，想象同样在"完成任务"后静止，见 §2.3。

### 1.3 想象画质与块边界

PSNR 是想象帧的 agentview 区域对配对真值帧的结果，按块取均值，3 个锚平均。块从 0 编号，第 0 块从真实画面出发，不计入下表：

| 口径 | 第 1–4 块 | 第 5–8 块 | 第 9–16 块 | 第一个块边界的下降 | 之后边界的最大下降 |
|---|---|---|---|---|---|
| 简单积分 | 21.8 | 19.8 | 18.8 | 2.7 / 3.9 / 3.6 dB | 1.2 dB |
| 沿用初始状态 | 24.9 | 19.9 | 17.8 | 1.6 / 3.9 / 3.9 dB | 1.7 dB |
| 标定控制器 | 26.0 | 21.1 | 19.4 | 0.9 / 3.9 / 2.2 dB | 2.0 dB |

- **32 步块边界没有系统性断崖。** 唯一明显的是第一个边界（第 0 块 → 第 1 块）：第 0 块从真实画面出发，第 1 块起改从生成画面出发。
- 画面质量本身很高：末段画面看起来接近模拟器渲染，没有 WorldVLA 那种退化。PSNR 的下降主要来自想象与现实的轨迹分叉，不是画质崩坏。

## 2. 拼接口径（单列）

### 2.1 第四选项（模型自己预测状态）：不存在

- 本体状态在模型里只是**输入**：10 维原始 EEF 经 min-max 归一化，由一个线性层（`proprio_encoder`）编码成一个上下文 token，追加在文本条件后（`base.py:506-545`）。
- 没有状态预测头；`generate` 只返回视频和动作（`base.py:1598-1604`）。
- 动作是 80 维统一空间，只有前 10 维有训练信号，其余维度不计损失、没有约束，不能当作状态读。
- 要从隐变量中解码状态，需要另外训练一个探针，那又是一个我们注入的部件。所以纯想象中块间的状态**必须由我们提供**。

### 2.2 三个口径的定义

| 口径 | 下一块的本体状态 |
|---|---|
| 简单积分 | 按 OSC 名义缩放积分本块动作：位置 += 0.05 m × 指令，姿态左乘 Exp(0.5 rad × 指令) |
| 沿用初始状态 | 每块都用锚的初始状态 |
| 标定控制器 | 用在真实重放上拟合的控制器模型积分本块动作（下述），**属于我们注入的部件** |

**标定控制器模型**：
- **数据**：只用真实重放，lingbot_base 的 100 条真值重放，逐位重放，逐步记录指令和实际末端状态；按 unit 分 70 条拟合、30 条留出（种子 20261036）。
- **模型**：位置和世界系姿态增量各用一阶 ARX，即"本步实际增量 = a·本步指令 + b·上步指令 + c·上步实际增量"，每轴 3 个系数；夹爪为一阶跟随。
- **产物**：参数 `controller/params.json`（SHA-256 `47db550a…`），拟合数据 `controller/data.npz`（SHA-256 `8a610e5b…`），尚未写入 protocol.yaml。

**留出验证**：30 条留出 unit，从每个块边界的真实状态出发，用真实指令滚 32 步，比较块末误差。

| 方法 | 位置误差中位数 / 90 分位 | 姿态误差中位数 / 90 分位 |
|---|---|---|
| 标定控制器 | **5.0 cm** / 9.9 cm | **3.2°** / 8.4° |
| 简单积分 | 52.8 cm / 97.1 cm | 34.4° / 92.6° |
| 沿用初始状态 | 6.3 cm / 18.0 cm | 9.1° / 29.3° |

简单积分严重高估了移动量。拟合出的稳态增益约为 0.0055 m/步/单位指令，约为名义值 0.05 的十分之一：控制器并不会在一步内走完指令的增量。

### 2.3 三口径实测（3 个锚 × 3 个口径，各一条完整想象）

**块边界状态误差**：送入第 c 块的想象状态，对比用该条想象自己的动作做真值重放、到第 32c 步时的真实末端。数值为 3 个锚的中位数。

| 口径 | 位置误差 第 1–4 / 5–8 / 13–16 块 | 姿态误差 第 1–4 / 5–8 / 13–16 块 | 真值 (a) 成功 |
|---|---|---|---|
| 简单积分 | 0.54 / 1.43 / 7.28 m（发散，离开工作空间） | 125° / 121° / 89° | **0/3** |
| 沿用初始状态 | 0.18 / 0.18 / 0.35 m | 40° / 106° / 135° | **0/3** |
| 标定控制器 | **0.09 / 0.18** / 1.12 m | **4.6° / 9.6°** / 48° | **3/3**（第 161、178、225 步） |

- **标定控制器口径**在任务进行的前 8 块（约 256 步）内，位置误差约 9–18 cm、姿态误差约 5–10°，明显优于另两个口径。之后误差累积增大，因为开环积分没有任何反馈，但那时任务已经完成，手臂基本静止。
- **"沿用初始状态"的姿态一致性最差**，与预期一致：第 5 块后姿态误差超过 100°。
- **"简单积分"发散**：位置误差到第 16 块达到 7–9 m。

**想象质量对口径的敏感度**：前 4 块的 PSNR 为标定 26.0 > 沿用初始 24.9 > 简单积分 21.8 dB，后段三者趋同（18–19 dB）。

**想象终点**（`runs/compare_chains_end.png`）：**9 条想象的结尾都"像成功"**：t5 的书不在桌上、夹爪停在后格上方；t3 的抽屉关着、看不到碗。但只有标定口径的 3 条现实成功，另 6 条现实失败：现实中书还在桌上，或碗留在柜外、抽屉开着。也就是说，**在状态输入有误时，OpenWAM 同样出现"想象替现实完成任务"的乐观偏差。**

### 2.4 结论与建议

1. **长程想象的脆弱性证据（记入预检）**：同一个锚、同一个种子，只换块间状态的来源，真值结局就从 0/3 变成 3/3。这说明它的长程想象（训练外的链式用法）高度依赖一个它自己不预测的量，而它的想象画面在三种口径下都显示成功。这一点本身就是关于"想象 verdict 可信度"的发现。
2. **建议口径：标定控制器。** 理由：留出验证误差最小；块边界误差在任务进行期内最小；它是三者中唯一让"同一串动作在现实中能复现成功"的口径。按裁决要求，它是我们注入的部件：拟合数据只来自真实重放，留出误差已报出，参数与拟合数据的 SHA 待写入 protocol.yaml，表格脚注声明，与 WorldVLA 的约束重试同等对待。
3. **已知局限**：控制器模型在 LingBot 的动作分布上拟合，而 OpenWAM 动作的幅度分布不同（平均 |xyz| 0.15–0.31）。块边界误差在第 8 块之后累积到米级。如果正式批次中有任务在 256 步后仍需大幅运动，这个口径的可信度会下降。

## 3. 判据迁移预估（不训练）

- **视角差异**：OpenWAM 的画面是 320 × 384 的 L 形画布（agentview 320 × 256 在上，腕部 160 × 128 在左下），LingBot 判据读的是 128 × 256 的"agentview | 腕部"并排拼接。两路相机都在，可以按几何关系裁切、缩放、重排成 LingBot 的视角格式。但相机分辨率（256 对 128）、缩放核和生成器都不同，属于分布迁移。
- **画质**：OpenWAM 生成帧接近模拟器渲染、没有退化，比 WorldVLA（生成帧行 TPR 0.05–0.06）好得多，迁移有希望。但 verdict 要可信，仍需要它自己的生成帧行，以及 t3 的"抽屉关着"子集检查。
- **成本**：模型很快（一次调用 0.6 秒），生成帧行的成本估计在 1 GPU·h 以内。
- 本次没有训练、也没有评测任何判据。
